# WAZ — خرائط العراق

نسخة WAZ الاحترافية المبنية كتطبيق ويب/PWA مع دعم RTL والعربية.

## المزايا
- MapLibre + OpenStreetMap
- GPS وتحديد الموقع
- بحث عربي عبر Nominatim
- توجيه عبر OSRM مع رسم المسار
- تقارير طريق محلية محفوظة على الجهاز
- PWA قابلة للتثبيت
- واجهة RTL مناسبة للهاتف
- جاهز للانتقال لاحقًا إلى بنية self-hosted للعراق (PostGIS/Valhalla/TileServer)

## التشغيل
```bash
npm install
npm run dev
```

## الإنتاج
```bash
npm run build
npm run preview
```

> ملاحظة: النسخة الحالية تستخدم خدمات OSM العامة كنقطة تشغيل. قبل الإطلاق التجاري الواسع يجب نقل الخرائط والبحث والتوجيه إلى بنية مستضافة ذاتيًا والالتزام بسياسات مزودي البيانات.
